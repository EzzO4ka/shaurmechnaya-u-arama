# 🔥 У Арама — сайт шаурмечной

Простой и современный сайт для шаурмечной **«У Арама»** в Санкт-Петербурге.

📍 **Адрес:** Санкт-Петербург, Апраксин переулок, 1

Сайт содержит меню, онлайн-форму заказа, контактную информацию и ссылку на Яндекс Карты.

---

## 🌯 Возможности

- 🏠 Главный экран с названием заведения
- 🌯 Меню с блюдами и ценами
- 🛵 Кнопка «Заказать онлайн»
- 📝 Форма оформления заказа
- 👤 Поле для имени клиента
- 📱 Поле для номера телефона
- 📍 Поле для адреса доставки
- 💬 Комментарий к заказу
- 💰 Автоматический расчёт стоимости
- ✅ Уведомление после оформления заказа
- 🗺️ Кнопка перехода в Яндекс Карты
- 📱 Адаптация под мобильные устройства
- ✨ Плавные эффекты и современный дизайн

## 📁 Структура проекта

```text
/
├── index.html
└── README.md


Весь сайт находится в одном файле index.html.

🚀 Запуск
Вариант 1 — открыть локально

Скачайте проект:

git clone https://github.com/USERNAME/REPOSITORY.git


Перейдите в папку проекта:

cd REPOSITORY


После этого просто откройте:

index.html


в браузере.

🌐 Публикация через GitHub Pages

Загрузите index.html и README.md в GitHub.

Откройте Settings репозитория.

Перейдите в Pages.

В разделе Build and deployment выберите:

Source: Deploy from a branch

Branch: main

Folder: / (root)

Нажмите Save.

После этого GitHub создаст публичную ссылку на сайт.

🗺️ Яндекс Карты

Кнопка «Как нас найти» ведёт непосредственно на точку заведения в Яндекс Картах:

https://yandex.ru/maps/-/CXUJERMq

🛵 Онлайн-заказ

На сайте есть всплывающее окно заказа.

Пользователь может указать:

выбранное блюдо;

количество;

имя;

номер телефона;

адрес доставки;

комментарий.

После заполнения формы появляется сообщение:

✅ Заказ принят!

⚠️ Важно

В текущей версии заказ не отправляется на сервер.

JavaScript только показывает уведомление об успешном оформлении.

Для настоящей системы заказов можно подключить:

Telegram Bot;

email;

backend на Node.js / PHP / Python;

базу данных;

CRM;

API службы доставки.
